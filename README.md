# GymTracker

Локальный трекер силовых тренировок для iPhone на React Native, Expo SDK 57 и
TypeScript. Разработка и ручная проверка идут через Expo Go; бесплатная целевая
поставка запланирована как устанавливаемая офлайн-PWA без backend. Сейчас
реализован функциональный MVP: каталог упражнений, запись, история и клонирование
тренировок, безопасная архивация упражнений и график прогресса. Данные хранятся
локально в SQLite; полный снимок можно экспортировать и восстановить из
версионированного JSON-файла в пустое хранилище.

## Запуск на Windows и iPhone

1. Установите Node.js 22.13 или новее и выполните `npm install`.
2. Установите совместимую с Expo SDK 57 версию Expo Go на iPhone.
3. Авторизуйтесь в Expo Go и Expo CLI под одной учётной записью.
4. Подключите компьютер и iPhone к одной сети Wi-Fi.
5. В корне проекта выполните `npm start`.
6. Отсканируйте QR-код камерой iPhone и откройте проект в Expo Go.

Если локальная сеть блокирует соединение, запустите `npm start -- --tunnel`.

### Авторизация Expo на Windows

Для аккаунта, созданного через Google, используйте браузерный вход, а не
корпоративный SSO:

```powershell
npx expo login --browser
npx expo whoami
```

Если Windows не может автоматически открыть браузер и команда завершается с
ошибкой `cmd.exe /c start`, отключите автозапуск браузера:

```powershell
$env:BROWSER = 'none'
npx expo login --browser
```

Скопируйте свежую ссылку из терминала в браузер вручную и не закрывайте терминал
до завершения входа. Ссылка содержит одноразовый локальный callback и перестаёт
работать после остановки команды. Не публикуйте ссылку целиком: она содержит
временные параметры авторизации.

## Проверка

`npm run verify` одной командой проверяет форматирование, lint, TypeScript,
тесты и совместимость конфигурации Expo.

Текущий статус и точка продолжения описаны в `docs/checkpoint.md`.

Production-web собирается командой `npm run export:web` в каталог `dist`. После
сборки скрипт создаёт service worker с хешем и точным списком файлов, чтобы PWA
целиком заменяла кэш приложения между версиями.

Постоянный адрес PWA — `https://psvmchannel.github.io/gymtracker/`. Публикацию
вручную запускает владелец репозитория через workflow `Deploy PWA to GitHub
Pages` в GitHub Actions; web-сборка использует базовый путь `/gymtracker/`.

## План поставки

Функциональный MVP сначала стабилизируется в Expo Go. Затем приложение получает
версионированный экспорт/импорт и web-адаптер локального хранилища, после чего
публикуется на бесплатном статическом HTTPS-хостинге как PWA. После первой
загрузки она должна запускаться с домашнего экрана iPhone без сети. Данные
тренировок остаются на устройстве; для защиты от очистки браузерного хранилища
предусмотрена файловая резервная копия.
